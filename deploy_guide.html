🏫 智慧學校會議紀錄系統 - 快速部署面板

此工具已將您所需的 Google Apps Script 程式碼全數備妥，請按以下 4 步完成設定。

1
建立 Google Drive 資料夾並取得 ID

請前往您的 Google Drive 建立兩個資料夾：

  • 會議照片專區：點進資料夾，網址最後面的字串即為 PHOTO_FOLDER_ID。
  • 會議範本庫：點進資料夾，網址最後面的字串即為 TEMPLATE_FOLDER_ID。
  • 前往 Google AI Studio 點選「Get API key」取得免費的 GEMINI_API_KEY。
2
建立 Google Docs 並開啟 Apps Script
  1. 在 Google Drive 建立一份新的 Google Docs 文件。
  2. 點擊選單列上的 「擴充功能」 > 「Apps Script」。
  3. 點擊左側 ⚙️ 「專案設定」，勾選 「在編輯器中顯示『appsscript.json』資訊清單檔案」。
3
貼上專案檔案內容

請依序建立與覆蓋以下 4 個檔案：

appsscript.json (覆蓋專案設定內的 appsscript.json) 
{
  "timeZone": "Asia/Taipei",
  "dependencies": {},
  "exceptionLogging": "STACKDRIVER",
  "runtimeVersion": "V8",
  "oauthScopes": [
    "https://www.googleapis.com/auth/documents",
    "https://www.googleapis.com/auth/drive",
    "https://www.googleapis.com/auth/script.external_request"
  ],
  "webapp": {
    "executeAs": "USER_DEPLOYING",
    "access": "ANYONE"
  }
}
Code.gs (主程式碼 - 內建自動查詢最新 Gemini Flash 版本，並以 gemini-3.6-flash 為備援)
TagSidebar.html (點選左側「+」>「HTML」，檔名輸入 TagSidebar)
Mobile.html (點選左側「+」>「HTML」，檔名輸入 Mobile)
4
發布與部署為 Web 應用程式
  1. 點選編輯器右上角 「部署」 > 「新增部署作業」。
  2. 類型選擇 「網路應用程式」 (Web app)。
  3. 執行身分：選擇 「我」；誰可以存取：選擇 「任何人」 (Anyone)。
  4. 點擊 「部署」 並完成一次性 Google 帳號授權。
  5. 將產生的 Web App 網址 傳至手機 Safari 或 Chrome，即可開始雙模現場錄音與拍照！
🎉 部署完成後，重新整理 Google Docs，頂部選單即會出現 「✨ AI 會議助手」！
